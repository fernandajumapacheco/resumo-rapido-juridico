# Política de segurança

## Escopo

O Resumo Rápido Jurídico foi projetado para funcionar apenas no computador do usuário. Não envie documentos jurídicos, dados pessoais, certificados, chaves ou tokens ao relatar um problema.

## Como relatar

Abra uma issue sem informações sigilosas e descreva somente os passos necessários para reproduzir o problema com conteúdo fictício. Se a falha exigir dados sensíveis para ser demonstrada, não os publique; informe apenas que é necessário um canal privado.

## Práticas recomendadas

- Execute o servidor em `127.0.0.1`.
- Mantenha a pasta `dados/` fora do Git.
- Não publique certificados ou chaves locais.
- Revise dependências antes de atualizar versões.
- Faça testes apenas com documentos fictícios.
